What is agent-aesthetics?
A personal soft-brutalist-document reference for projects vibe-coded with LLM agents. The kit includes design tokens, prose rules, and reference pages.
Why magenta?
Accent color picked from a comparison of palettes — magenta carries identity without leaning warm, and the syntax palette harmonizes around it.
Can I use other palettes?
Use the top palette row to switch — your choice persists across pages.

Code

Inline code and code blocks. Syntax tokens are semantic, not just highlighting.

Inline
Run with --verbose to see paths like /work/example/ and addresses like 0x4012a0. Use await in async contexts. The return type is Promise<Result>.
Block
TS
export async function fetchRun(id: string): Promise<Run> {
  const r = await fetch(`/api/runs/${id}`);
  if (!r.ok) throw new RunError('fetch failed');
  return r.json();
}
