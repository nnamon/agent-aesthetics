agent-aesthetics

A personal soft-brutalist-document reference. Cool magenta palette family, document-first chrome, two type families (system sans + monospace), thin rules instead of shadows, semantic syntax color in prose.

Use the top nav to switch pages. Use the palette row to switch palette variants. The choice persists across pages.

Page templates

Log

Run timeline with breadcrumbs, metadata sidebar, code blocks. Good base for activity logs, audit trails, replay views.

Dashboard

KPI tiles, bar chart, status breakdown, activity table. The default "data app" shape.

Reader

Long-form article with sticky TOC, blockquotes, lists, tables, inline syntax tokens. Article / blog / writeup.

Chat

List of conversations + threaded messages + composer. Generic messaging — support, social, assistant.

Charts

Line, bar, area, donut, sparkline, scatter, heatmap. How the palette translates to data viz.

Game

Text-adventure HUD: location bar, scene + side panel, command log. Pattern for monospace-heavy panels.

Settings

Sticky section nav, fields with labels + hints, toggles, API key table, danger zone.
Patterns

Components

Atomic UI catalog — buttons, forms, alerts, toasts, modals, tabs, accordions, progress, avatars, pagination, breadcrumbs, kbd, tooltips.

Sign in

Centered auth card with form + OAuth row + footer link. Drop-in pattern for any auth screen.

404 / Empty

Error landing and the inline empty-state pattern for lists, tables, and panels with no data.
